⚡ Key Innovations
Weighted Cross-Entropy
Solved the 3:1 class imbalance by applying inverse-frequency weights to the loss function during training.
Transfer Learning
ImageNet pre-trained weights provide robust low-level texture and edge detectors, dramatically reducing training time.
Real-time Grad-CAM
Gradient-weighted Class Activation Mapping overlaid on the original scan for clinical interpretability and radiologist trust.
